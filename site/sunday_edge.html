Player projections

Next Gen Stats · PFR · snaps · play-by-play

Projection is the median outcome. The range is the middle half of outcomes (25th to 75th percentile). Opp factor is how much the opponent allows to this position versus league average. Players listed Out on the latest report are flagged.

Game board

Home team spread · negative = home favored

Market is the consensus line. Model uses EPA, early-down EPA, explosive-play rate, PFR pressure rates, CPOE, pass rate over expected, rest and weather. It gets about 6% weight against the market on spreads, so a gap here is a lead, not a bet.

How the models tested

Game model alone vs closing lines

Each season predicted using only earlier seasons. Rows group bets by how much edge the model believed it had.

Bigger claimed edges lost more. Public stats don't beat closing NFL lines on their own, so game plays require FanDuel to be off the other books, with the model as one supporting signal.

Prop projection accuracy

Probabilities are calibrated: when the model says 60%, it hit about 58–60% in testing. Historical prop lines aren't public, so prop betting results are tracked live above.
